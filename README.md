# mymoney — 理财净值历史

个人记录用网页，部署到 Cloudflare Pages 后打开 `index.html` 即可查看。

## 包含什么
- 8 个理财产品的净值历史：每只最近 30 条，最新净值日 2026-10-23
- 每只产品的登记编码、子份额代码、管理人、官方全称、中国理财网详情页链接
- 最新净值、近 1 个月 / 近 3 个月 / 成立以来年化（平台过往业绩原样）
- 净值走势图、逐日历史表，日涨跌和当日万收由净值历史在本页算出（当日万收 = 净值变化 × 10000，每万份）
- 新增一日净值后可本页重算、导出 JSON

## 数据来源
中国理财网·理财行业统一信息披露平台，公开查询。过往业绩不代表未来表现，不构成收益承诺。

## 持仓与隐私说明
净值数据是公开数据。`holdings.json` 是用户要求同步的 2026-10-23 持仓快照（总额 1,457,640.87 元），持仓为用户自填记录，未与银行账户直接核对，以银行 App / 对账单为准。本仓库目前为公开仓库，同步后持仓金额在仓库和部署后的页面上可见；如需改为私人，请在 GitHub 仓库设置里自行改为私人，Pages 绑定需相应授权私人仓库。

## Cloudflare Pages 部署
在 Cloudflare Pages 里新建项目，选择连接 Git，选这个仓库，构建命令和输出目录都留空（纯静态页），部署后访问分配的 pages.dev 域名即可。以后更新净值数据时，把新的 `nav-history.json` 推到仓库，Pages 会自动重新部署。
